# Decision Log

One file per decision, numbered in order: `0001-stack.md`, `0002-positioning.md`, ...

Each entry answers:

- **Context:** what problem or question prompted the decision
- **Options:** what was considered
- **Decision:** what was chosen
- **Why:** the reasons, including what was learned in the gate
- **Consequences:** what this makes easier or harder
